## 1. Commands Used for Checking and Modifying Permissions
 Check permissions: ls -l filename
 Modify (numeric): chmod 755 filename and chmod 755 directoryname
 Modify (symbolic): chmod u+x filename
 Change ownership: chown -R owner:group directoryname

## 3. Significance in Cybersecurity
File and directory permissions are critical for the Principle of Least Privilege. If permissions are too broad (like 777), any user can read, modify, or execute sensitive data. Setting correct permissions (like 755 for directories) restricts unauthorized access, prevents data breaches, and stops attackers from modifying system files.
